# ELT repository instructions

Before beginning any task in this repository, read `DEFERRED-WORK.md` and follow its required workflow. It is the canonical source of truth for intentionally postponed work.

Every final task report must state which deferred-work register items were added, changed, completed, or left unchanged. Do not mark an item complete without satisfying its acceptance criteria and recording concrete evidence. Report prompt/register conflicts instead of silently dropping tracked work.

More specific nested `AGENTS.md` files continue to apply within their directories.
